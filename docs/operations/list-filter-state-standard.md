# 列表筛选状态规范

## 适用规则

- 搜索词、业务状态、人员、标签、来源、日期等属于临时业务筛选。
- 用户离开业务模块后，再次进入列表时，临时业务筛选必须恢复默认值，页码回到第 1 页。
- 每页条数、列显示、列顺序和列宽属于用户视图偏好，可以保留。
- 在当前列表内打开或关闭详情、编辑和审核弹窗，不视为离开模块，不得清空当前筛选。
- URL 中用于明确导航的页签、详情 ID、审核目标和导入批次等参数，不作为普通筛选统一清理。

## 实现约束

- 使用全局 Store 保存筛选的列表，必须提供 `resetListFilters`，只清理临时筛选并保留每页条数。
- 页面统一调用 `useResetListFiltersOnPageExit(resetListFilters)`，禁止各页面自行复制卸载清理逻辑。
- 仅使用组件本地状态且会随路由卸载的筛选，无需重复接入全局重置 Hook。
