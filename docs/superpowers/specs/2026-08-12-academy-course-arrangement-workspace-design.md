# 极享商学院课程安排工作台重构

## 决策

保留课程执行能力，取消独立“场次执行”一级页面。课程安排是业务主体，准备、执行、学员、转化和单场复盘均在课程安排右侧抽屉内完成。

## 一级导航

- 运营工作台
- 课程资产
- 课程安排
- 学员与转化
- 经营复盘

旧 `/academy/sessions` 地址兼容跳转至 `/academy/plans`；旧学员和转化地址统一跳转至 `/academy/learners`。

## 课程安排页面

- 周历用于快速查看和按日期新建课程安排。
- 汇总本周安排、计划邀约、目标成交、准备进度和风险安排。
- 全量列表支持搜索、状态筛选、统一分页及下一步操作。
- 下一步操作根据安排状态和准备任务动态显示。

## 课程安排抽屉

点击周历卡片、表格行或下一步按钮均打开右侧抽屉，不替换列表页面。抽屉包含：

1. 安排概览
2. 准备与执行
3. 学员管理
4. 转化交接
5. 经营复盘

准备与执行复用现有九阶段任务、提交验收和开课门禁；学员、订单和复盘继续复用现有后端接口。

## 验收标准

- 不再显示独立“场次执行”导航和重复列表。
- “课程排期”统一命名为“课程安排”。
- 课程安排详情使用右侧抽屉，关闭后列表筛选和页码不变。
- 必做准备未完成时只引导完善准备；完成后才显示确认开课。
- 待开课、进行中、已完成安排分别显示对应下一步操作。
- 学员、转化和单场复盘可在同一课程安排抽屉内查看和处理。
- 跨课程学员与转化、经营复盘仍保留汇总视图。
