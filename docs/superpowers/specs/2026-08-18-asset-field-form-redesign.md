# 资产字段模型与统一分区表单设计

日期：2026-08-18  
状态：已确认

## 1. 目标

设备资产、手机号资产和互联网账号改用极享OS已有的分区业务表单。本次不只改视觉，同时拆分混合字段、统一归属语义、放宽手机号未绑定设备的合法状态，并保留旧数据读取兼容。

## 2. 关系与边界

- 设备资产是物理硬件；设备通信配置决定 IMEI 和卡槽规则。
- 手机号资产是号码与 SIM/eSIM 服务身份；可处于未绑定设备状态。
- 互联网账号是平台账号；可绑定手机号，通过手机号间接查看当前设备。
- 设备换卡、手机号换机、账号换绑都只改变关系，不新建或替换资产身份。
- 账号密码不存储在资产模块。

## 3. 统一 UI

- 新增和编辑统一使用 `DialogCloseTitle`、`BusinessFormSection`、`ProtectedFormDialog`。
- 标题区包含标题和一句用途说明；内容区可滚动；底部操作栏固定。
- 桌面端两列，移动端单列全屏。
- 每个分区显示步骤编号、标题、已填摘要或缺失必填数；校验失败自动展开相应分区。
- 从固定资产页签进入时不再显示禁用的“资产类型”字段。

## 4. 设备资产字段

1. 设备信息：设备编号（系统生成）、设备名称、设备类别、品牌、型号、序列号 SN。
2. 硬件与通信标识：通信配置（无SIM/单卡/双卡/eSIM）、IMEI 1、IMEI 2。无SIM不填 IMEI，单卡和 eSIM 只填 IMEI 1，双卡填两个 IMEI。
3. 归属与使用：资产权属、管理部门、资产负责人、当前使用人。
4. 状态与成本：库存中/使用中/维修中/闲置/已停用/已报废，取得方式（购买/租赁/借用）、购买金额或月租费用、取得日期、保修到期日、备注。

## 5. 手机号资产字段

1. 号码与 SIM：手机号、SIM 形态（实体SIM/eSIM）、ICCID、IMSI、实名主体、实名信息、运营商和归属地。
2. 设备绑定：当前绑定设备和卡槽。设备可为空；未选设备时卡槽也必须为空。
3. 归属与使用：资产权属、管理部门、资产负责人、当前使用人。
4. 套餐与状态：套餐名称、月套餐费、合约到期日、待启用/使用中/停机保号/已停用/已注销、备注。

ICCID、IMSI 是敏感字段，展示、查看和导出沿用现有敏感字段权限。

## 6. 互联网账号字段

1. 平台与账号：业务平台（系统字典）、账号名称、登录账号、账号类别、实名主体和实名信息。
2. 安全与绑定：绑定手机号、绑定邮箱、二次验证方式；当前设备只读推导。
3. 归属与使用：资产权属、管理部门、账号负责人、当前使用人、外部服务商。
4. 经营与状态：账号用途、业务场景、账号状态（使用中/闲置/异常/封禁/已注销）、控制权状态（已掌控/待交接/离职待回收/已回收）、月服务费、服务到期日、备注。

## 7. 兼容和完成标准

- 旧 `brandModel`、`simType`、`monthlyCost`、`permissionStatus` 在读取时映射到新字段；新表单和新导入使用新语义。
- 列表、详情、搜索、导入、导出与新增/编辑表单的字段名称一致。
- 无SIM、单卡、双卡、eSIM 的 IMEI 校验正确；手机号可未绑定设备；账号控制权状态参与离职回收。
- 敏感字段仍按权限掩码和记录查看日志。
