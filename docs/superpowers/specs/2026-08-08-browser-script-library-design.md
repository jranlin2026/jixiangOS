# 极享AI浏览器员工统一话术库设计

## 目标

把插件中写死的三个常用话术升级为极享OS统一管理的话术库。管理员维护分组、话术内容和匹配条件，客服按分组手动使用；插件识别订单状态后，可以自动推荐并填入一条匹配话术，但第一阶段绝不自动发送。

## 产品边界

本阶段实现：

- 公司统一话术库，所有客服读取同一份配置。
- 系统管理员新增、编辑、排序、启停和删除分组及话术。
- 客服按分组浏览话术并手动填入飞鸽输入框。
- 每条话术配置订单状态、商品关键词、联系方式状态和优先级。
- 识别到订单状态后自动匹配并填入回复框。
- 保存管理员、更新时间和配置版本。

本阶段不实现：

- 自动点击飞鸽发送按钮。
- 由AI自由生成未经审核的话术。
- 多层嵌套分组。
- 复杂表达式、脚本或通用规则引擎。
- 根据未校准、未识别的订单状态猜测并填入话术。

## 方案选择

采用“极享OS服务端统一配置 + 插件读取和调用”。配置保存于现有 `appStorage`，使用独立键 `browser_employee_script_library_v1`。该方案比浏览器本地保存更适合公司统一管理，又比新增多张规则表更符合当前MVP规模。

后续如果话术数量、审批或多平台规则显著增长，可以把相同领域接口迁移到独立数据表，插件协议无需改变。

## 领域模型

```ts
type ScriptLibrary = {
  schemaVersion: 1;
  revision: number;
  groups: ScriptGroup[];
  updatedAt: string;
  updatedBy: { id: string; name: string };
};

type ScriptGroup = {
  id: string;
  name: string;
  enabled: boolean;
  sortOrder: number;
  scripts: ScriptTemplate[];
};

type ScriptTemplate = {
  id: string;
  title: string;
  content: string;
  enabled: boolean;
  sortOrder: number;
  priority: number;
  match: {
    orderStatuses: string[];
    productKeywords: string[];
    contactState: 'ANY' | 'MISSING' | 'PRESENT';
  };
};
```

规则含义：

- `orderStatuses` 为空表示不限制订单状态；非空时必须与飞鸽识别出的标准化状态完全匹配。
- `productKeywords` 为空表示不限制商品；非空时任一关键词命中商品名称即可。
- `contactState` 判断当前会话是否已经获得手机号或微信。
- `priority` 数值越大越优先。
- 分组只负责组织和展示，不隐式改变匹配语义，避免移动分组后意外改变自动化行为。

初始配置迁移现有“下单欢迎、索要联系方式、站外联系”三个话术，放入“下单客户”分组。初始话术不配置自动匹配条件，防止真实订单状态尚未校准时误触发。

## 权限

- 已登录且具备线索录入权限的客服可以读取启用的话术库。
- 只有系统管理员可以修改话术库。
- 后端必须执行权限判断，不能只依赖插件隐藏编辑按钮。
- 客服读取接口不返回已删除内容；停用内容保留在管理数据中，但不会出现在客服使用区或自动匹配候选中。

## API

```text
GET /api/browser-agent/script-library
PUT /api/browser-agent/script-library
```

`GET` 返回当前完整话术库。`PUT` 由系统管理员提交完整配置和当前 `revision`。服务端校验名称、内容、枚举、排序值、优先级和ID唯一性；revision不一致返回 `409`，要求管理员刷新后重新编辑，避免两个管理员互相覆盖。

每次成功保存后服务端将 `revision + 1`，并覆盖 `updatedAt`、`updatedBy`。插件不允许提交操作者信息。

## 插件交互

### 客服使用区

- “常用话术”改为分组标签或下拉选择。
- 当前分组下展示启用的话术卡片。
- 点击卡片只填入飞鸽输入框，仍由客服检查和发送。
- 自动匹配的话术显示“系统推荐”和命中原因。
- 无匹配时不推荐、不自动填入，客服仍可手动选择。

### 管理区

系统管理员看到“管理话术”入口，打开后可以：

- 新增、重命名、排序、启停和删除分组。
- 新增、编辑、排序、启停和删除话术。
- 编辑标题、内容、优先级及三个匹配条件。
- 保存整份配置或取消本次修改。

删除分组前必须明确提示该分组包含的话术数量。删除属于配置变更，不单独提供回收站；旧版本仍可从数据库备份及操作记录追溯。

## 自动匹配与填入

匹配只在页面上下文重新识别成功时运行，且必须识别到订单号和订单状态。

候选话术必须同时满足：

1. 分组和话术均启用。
2. 订单状态条件匹配。
3. 商品关键词条件匹配。
4. 联系方式状态条件匹配。

候选排序依次为：

1. `priority` 降序。
2. 已配置条件数量降序，条件更具体者优先。
3. 分组 `sortOrder` 升序。
4. 话术 `sortOrder` 升序。
5. 话术ID升序，保证结果稳定。

自动填入还必须满足：

- 飞鸽回复框当前为空。
- 当前订单尚未自动填入过同一话术。
- 客服没有开始人工输入。

任何情况下都不覆盖回复框已有内容。自动填入后只显示推荐状态，不点击发送按钮。

## 页面识别扩展

`FeigePageContext` 增加：

```ts
orderStatus: string;
```

订单状态必须来自真实飞鸽订单卡片并经过标准化。页面未找到订单或状态时返回空字符串并记录诊断信息，匹配器随即跳过自动填入。

当前已校准无订单会话。订单状态选择器必须在一笔真实有订单会话中验证后才能启用自动匹配。

## 容错

- 极享OS暂时不可用：显示话术库加载失败，不使用未经确认的旧配置自动填入。
- 配置为空：显示空状态，管理员可以创建第一个分组。
- 配置校验失败：服务端拒绝整次保存，保留编辑内容并显示具体字段错误。
- revision冲突：不覆盖服务端版本，提示刷新。
- 飞鸽页面未识别订单状态：允许手动使用话术，不执行自动匹配。
- 飞鸽输入框已有内容：只显示推荐，不覆盖、不追加。

插件可以缓存最近一次成功读取的话术库用于手动浏览，但缓存内容不得参与自动填入，除非本次会话已经从服务端成功确认同一revision。

## 测试

- 话术库校验：空名称、空内容、重复ID、非法枚举和revision冲突。
- 权限：客服可读不可写，系统管理员可读可写。
- 匹配器：订单状态、商品关键词、联系方式状态、优先级、具体度和稳定排序。
- 安全填入：空输入框可以填入；人工已有内容绝不覆盖；同一订单同一话术不重复填入。
- 页面适配：有订单、无订单、状态未识别三种真实结构夹具。
- 回归：现有手动话术填入、客户识别、联系方式识别、线索入库和订单备注流程继续通过。

## 发布顺序

1. 服务端话术库模型、校验、权限和API。
2. 插件分组展示及管理员编辑界面。
3. 纯函数匹配器与推荐提示。
4. 使用真实有订单飞鸽会话校准订单状态。
5. 打开“自动推荐并填入”，保持人工确认发送。
