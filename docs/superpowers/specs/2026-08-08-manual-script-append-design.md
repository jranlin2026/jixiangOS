# 手动话术追加设计

## 目标

客服手动点击话术卡片时，如果飞鸽回复框已有文字，在原文末尾换行追加新话术，不覆盖原文，不自动发送。

## 行为边界

- 手动点击话术：空输入框直接填入；非空输入框用一个换行符追加。
- 若原文已经以换行结尾，不再额外增加空行。
- 系统自动推荐：继续使用“仅空输入框可填入”的安全策略，不追加、不覆盖。
- 两种行为都必须在写入前核对客户和订单上下文，且不点击发送按钮。

## 技术方案

在飞鸽页面适配器中新增 `appendReply()`，复用现有的输入框识别、上下文校验和 `input/change` 事件派发。内容脚本新增 `APPEND_FEIGE_REPLY` 命令，侧边栏的手动卡片点击改用该命令；自动推荐仍使用 `FILL_FEIGE_REPLY_IF_EMPTY`。

## 验证

适配器测试覆盖 textarea 空值、已有文本、已有换行结尾三种情况，并保留自动推荐不覆盖的现有测试。最后运行插件全部测试、类型检查和构建。
